# 初回体験・作成フロー再設計 (#705 × #673 統合設計)

2026-08-28 設計確定（ユーザー方針承認済み）。LPの約束「誰でも5分で」を実際の初回体験と一致させる。

## 現状の問題
- LP→ログイン→home→オンボ→キャラ生成→home→主人公選択→作り方→テンプレ→入力→スタイルで**最大10画面**
- ステップ表示は「3」だが実画面は最大6（複数画面が currentStep={1} を使い回し）
- キャラクター生成(30秒〜1分)が初回の必須級動線に割り込み、絵本を1冊も見る前に2回待たされる

## 設計: 2トラック制

### Track A「おまかせでつくる」(初回デフォルト)
```
ログイン → 子ども登録(名前+年齢のみ #703) → おすすめテンプレ3択 → 生成開始
```
- 目標: **LPから4画面・実質5分で初回絵本完成**
- テンプレ3択は年齢帯からの自動推薦（fixed_template。最速・安定・無料枠消費1）
- スタイルは推薦テンプレの既定値を使用（選択画面スキップ）
- **キャラクター生成は初回フローから完全に外す** → 絵本生成の待ち時間(2-5分)中に
  「待っている間に、なかよしキャラを作ってみませんか？」で案内（待ち時間の有効活用）

### Track B「こだわってつくる」
- 既存のフルフロー（作り方選択→…→スタイル）を維持
- ステップ表示を実画面数に一致させる（「全6ステップ中n」）
- 入口: 本棚の「絵本を作る」メニューで A/B を常時選択可能

## 実装フェーズ
| Phase | 内容 | 規模 | 担当 |
|---|---|---|---|
| P1 | ステップ表示の実数化（Track B画面のcurrentStep修正） | S | jules-ready |
| P2 | Track A: おすすめテンプレ3択画面 + 直行ルート + 初回判定 | M/L | jules-ready(詳細spec付き) |

| 済 | #701 returnTo / #702 登録後直結 / #703 フォーム軽減 / #704 価値提示 | - | 起票済み |

## P2 の仕様要点
- 初回判定: `books.length === 0 && children.length <= 1`（ユーザードキュメントへのフラグ追加はしない）
- おすすめロジック: 子どもの年齢 → age-reading-profile の年齢帯 → activeなtemplatesから
  order上位3件（既存の \`templates\` コレクション・composite index流用、新index不要）
- 3択画面は既存 select-template のコンポーネントを再利用し「もっと見る→Track B」退避線を用意
- 生成開始前に確認1行「無料プランの1冊を使って作成します（今月あと n 冊）」

## 計測

- Stage: リリース後2週間でLP→初回生成開始の到達率を#704の価値提示と合わせて評価
